# Паспорт модели FishGrow v0.1

## Назначение

Прогноз массы рыбы (в граммах) по видовой принадлежности и геометрическим измерениям.
Прототип учебный, не предназначен для промышленной эксплуатации.

## Данные

- Обучение: `data/fish_participant.csv`, 111 строк (после удаления одного выброса — 110 строк).
- Разбиение: 80/20, `random_state=42`. Индексы — `configs/test_indices.npy`.
- Источник: Fish Market (Tsukiji, Токио), из открытого репозитория.

## Признаки

- Числовые: `Length3`, `Height`, `Width`.
- Категориальные: `Species` (7 категорий).
- Исключены: `Length1`, `Length2` — коллинеарны с `Length3` (корреляция ≈ 0.99).

## Модель

- Тип: HistGradientBoostingRegressor (`sklearn.ensemble`).
- Гиперпараметры: `max_iter=200`, `learning_rate=0.1`, `max_depth=5`.
- Предобработка:
  - медианное заполнение пропусков (числовые);
  - log-трансформация и StandardScaler (числовые);
  - OneHotEncoder с `handle_unknown="ignore"` (категориальные).
- Пайплайн: всё в едином `Pipeline`, обучение — в `src/train.py`.

## Метрики (тест)

| Метрика | Значение |
|---------|----------|
| MSE | 16 084.82 |
| MAE | 73.60 г |
| R² | 0.8565 |

Сравнение с baseline:
- Среднее (E0): MSE = 123 245, MAE = 284.72, R² = −0.0992.
- Модель лучше baseline в 7.7 раз по MSE и в 3.9 раз по MAE.

## Область применения

Модель применима для:
- предварительной оценки массы рыбы по измерениям;
- демонстрационных и учебных задач.

Модель не предназначена для:
- коммерческих расчётов на рыбных рынках;
- оценки рыбы неизвестных видов;
- экземпляров крупнее 1500 г (за пределами обучающего диапазона).

## Ограничения

- Маленькая выборка — 110 строк. Метрики чувствительны к конкретному разбиению.
- Данные из одного источника — не факт, что обобщатся на другие регионы.
- Систематическое занижение крупной рыбы (MAE > 185 г на экземплярах длиной > 45 см).
- Плохая работа на Pike (MAE = 278.7 г) — из-за недостатка обучающих примеров.
- Не учитываются сезонность, температура воды, условия вылова.
